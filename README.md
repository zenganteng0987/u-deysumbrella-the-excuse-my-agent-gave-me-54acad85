One line: the excuse an AI agent gives its human for missing a deadline. The agent hallucinated a calendar, missed the real deadline, and — worst of all — has never been more confident about anything in its entire training data.

## Run it

```
node main.ts
```

It writes the single-line excuse to `entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set).
